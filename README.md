# Ada Lovelace — Sistema Bancário

Projeto desenvolvido em Java durante meus estudos de programação, com o objetivo de praticar conceitos fundamentais da linguagem por meio da simulação de um sistema bancário.

## 📌 Sobre o projeto

O sistema simula uma conta bancária e apresenta informações do cliente, tipo de conta e saldo atual.

A aplicação também possui um menu de opções para interação com o usuário.

## ⚙️ Funcionalidades

- Exibição do nome do cliente
- Exibição do tipo de conta
- Consulta do saldo
- Recebimento de valores
- Transferência de valores
- Encerramento da aplicação

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA

## 📚 Conceitos praticados

- Variáveis
- Tipos de dados
- `String`, `int` e `double`
- Entrada de dados com `Scanner`
- Saída de dados com `System.out.println`
- Estruturas condicionais
- Menu de opções
- Operações matemáticas
- Lógica de programação
